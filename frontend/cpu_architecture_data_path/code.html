ALU Combinational Path

The Arithmetic Logic Unit operates as pure combinational logic with zero inherent memory. When ALUSrc gates Register B into the second adder port, the propagated propagate-generate signals settle within <15ns. The 8-bit sum 0x1E stays on the internal bus until the clock edge latches.

Settling Delay: 14.2 ns [MET]
tune

Microcode & Control Lines

The Control Unit functions as a state machine micro-sequencer. During this Execute phase (T3), it asserts the tri-state output driver on the ALU while de-asserting memory lines to prevent data contention on the unified 8-bit bus. The destination latch in Register A will assert on T4.

Current Micro-Word: #0b10010010
flag

Flag Evaluation Logic

Flags are evaluated asynchronously at the output of the full-adder tree. Since 0x0A + 0x14 = 0x1E (30d), the result is non-zero (Z=0), positive sign bit 7 is low (S=0), and bit 8 carry out is unasserted (C=0).

Overflow Condition: V = C7 ⊕ C8 = 0
